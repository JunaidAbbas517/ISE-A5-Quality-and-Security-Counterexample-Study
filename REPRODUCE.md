# Reproduction

## Environment

| Item | Recorded value |
|---|---|
| OS | Windows 11 Pro 10.0.22631 |
| Python | CPython 3.12.4 |
| Database | PostgreSQL 16.2 (bundled in `pgserver==0.1.4`; no separate install) |
| Driver | `psycopg==3.3.9` (binary) |
| Study dependencies | `requirements.txt` (pinned) |
| Notebook / figures | `requirements-notebook.txt` (full `pip freeze` of the study venv, incl. matplotlib 3.8.4, nbconvert 7.17.2) |
| Report | Node 22.12.0 + `docx@9.0.2` (`report/package-lock.json`); PDF exported by Microsoft Word |

`pgserver` also ships Linux and macOS wheels, but only Windows was tested.

## 1. Set up

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## 2. Verify the frozen snapshot (optional, Git Bash)

```bash
cd target/app-under-test && sha256sum -c ../SNAPSHOT-SHA256.txt
```

## 3. Run the study

```powershell
.venv\Scripts\python harness\run_study.py --config before --runs 3   # baseline
.venv\Scripts\python harness\run_study.py --mutants                  # oracle check
.venv\Scripts\python harness\run_study.py --config after --runs 3    # + improvement/001
.venv\Scripts\python harness\posthoc.py                              # post-hoc PH-01/02 (not counted)
.venv\Scripts\python harness\compare.py                              # regenerates results/COMPARISON.md
```

Each command starts its own throw-away cluster in a temp folder, builds the database from
`harness/supabase_shim.sql` → `target/app-under-test/supabase/schema.sql` → [`improvement/*.sql`] → `harness/fixtures.sql`,
runs the cases, and writes new time-stamped files to `results/raw/`. Nothing is overwritten.

The message `unknown PostgreSQL timezone: 'UTC0'; will use UTC` comes from psycopg and is harmless (deviation D1).

### Expected output

```
before run k: counterexamples=['IN-04', 'IN-05', 'IN-10'] control_failures=[] valid=True
mutation score = 8/10 = 0.8   (M08, M09 survive)
after run k:  counterexamples=[] control_failures=[] valid=True
deterministic across runs: True
```

Run time is about 2 s per configuration and about 45 s for the mutation run, plus about 10 s to start the cluster.

## 4. Notebook

```powershell
.venv\Scripts\python -m pip install -r requirements-notebook.txt
.venv\Scripts\python -m ipykernel install --sys-prefix --name ise-a5 --display-name "ISE-A5 (.venv)"
.venv\Scripts\jupyter-nbconvert --to notebook --execute --inplace notebook\ISE-A5-Study.ipynb
```

Use the venv's own `jupyter-nbconvert` executable. `python -m jupyter` may hand off to another Jupyter on PATH.
The notebook is generated by `notebook/make_notebook.py`.

## 5. Report

```powershell
.venv\Scripts\python report\make_figures.py     # report/figures/*.png from results/raw
cd report; npm ci; node build_report.js          # ISE-A5-Final-Report.docx
```

The PDF was exported from the DOCX with Microsoft Word (`report/export_pdf.ps1`, or *File → Save As → PDF*).
